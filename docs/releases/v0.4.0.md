# dameng-cli 0.4.0

本次发布改善连接管理、插件更新和 shell 补全，并修复 SSH 私钥口令使用与卸载清理重试，同时完善宿主日志和应用资源控制。宿主与 SDK 为 0.4.0，内置 db、ssh 插件为 0.2.0。

## 连接与认证

- `dm ssh edit`、`dm db edit` 修改指定字段并保留其余配置与秘密；终端回车保留原值，保存前确认摘要。
- 同名新增需显式 `add --replace`，删除需确认或脚本传 `--yes`。
- `dm ssh connect [name]` 可按已保存连接选择登录；`ssh` 别名保留。
- 保存的私钥口令现在用于测试和登录。密码认证与已保存私钥口令应答都需要本机 `sshpass`；未保存口令的密钥连接直接使用系统 `ssh`。
- 密码和口令通过子进程环境传递，不再放进子进程参数。
- 数据库驱动暂未实现；`dm db test/exec` 继续明确报错，连接管理与迁移可正常使用。

## 插件管理

- `dm uninstall` 默认保留配置、连接、缓存和备份，重新安装可继续使用。彻底清空使用 `--purge`，脚本需显式加 `--yes`。
- 清理失败或中断时保留数据登记，修复报错路径后重试 `dm uninstall <name> --purge --yes`。`doctor --repair` 不会误删剩余数据。
- `dm update` 不带参数检查更新，指定名称或 `--all` 执行升级；原 `outdated`、`verify` 宿主命令移除，安装自动校验，后续诊断使用 `doctor`。
- 远程安装脚本记录持久的 GitHub Release 来源，内置插件可直接通过 `dm update` 升级；旧临时来源需重新运行新版安装脚本刷新。
- 宿主与内置插件增加 `config init/show/path`、插件环境诊断与更具体的错误提示。

## 日志与资源控制

- 诊断日志按本机日期写入 `<DM_PLUGIN_HOME>/logs/dm-YYYY-MM-DD.log`，保留当天及前 29 天；每个每日文件默认最多 5 MiB，满额时淘汰旧内容、保留新日志，不生成额外分卷。
- `[log] directory/max_size_mb` 或 `DM_LOG_DIR/DM_LOG_MAX_SIZE_MB` 可调整目录和大小上限。诊断日志写入失败或旧日志清理失败时不回退到 stdout/stderr；无法删除的旧日志不阻止当天日志写入。旧版 `dm.log` 和 `dm.log.1` 保持原样。
- 更新检查默认最多并发 4 个任务，可通过 `[update] check_concurrency` / `DM_UPDATE_CHECK_CONCURRENCY` 调整为 1..16。Release 校验采用 64 KiB 缓冲，插件列表批量读取元数据，数据库结果逐行输出。
- 配置与 Release 元数据最多 1 MiB，SQL 与连接导入最多 16 MiB；输入超限报错。Git/下载辅助进程输出分别最多 64 KiB，单进程最多运行 180 秒；单次下载最多 120 秒。
- 这些边界控制宿主与内置插件的主要开销，不提供第三方插件进程树的硬性 CPU/内存配额。

## 动态补全

支持 Bash 和 Zsh，覆盖宿主、已安装插件、子命令、选项、文件路径与保存的连接名。启用方式：

```sh
# Bash
source <(dm completions bash)

# Zsh
autoload -Uz compinit
compinit
source <(dm completions zsh)
```

第三方插件可声明 `completion = true` 与 `min_host_version = "0.4.0"`，实现 `completion-v1` 查询协议。查询只读，限制运行时间和输出，未启用的旧插件不会被执行。

## 安装与兼容性

安装脚本安装宿主、db 和 ssh；`dm self-update` 仅替换宿主。若只更新宿主，还需执行 `dm update --all` 更新插件。

发布资产覆盖 Linux x86_64/ARM64、Linux x86_64 musl、macOS Apple Silicon/Intel 和 Windows x86_64，归档附带 SHA-256 校验文件。最低 Rust 版本仍为 1.85。

新增补全清单字段要求宿主 0.4.0；旧宿主拒绝未知字段。现有连接数据库、加密数据与配置路径保持兼容。因卸载默认行为改变，依赖卸载删除数据的脚本需显式添加 `--purge --yes`。
