# dameng-cli v0.4.1

本次修复 sqllog2db v3.0.1 的 GitHub 安装：该版本只发布独立命令产物，宿主现在优先寻找标准插件文件，缺少时使用对应平台的 `sqllog2db-<target>`。兼容仅限 `guangl/dm-database-sqllog2db` v3.0.1，并保留校验与安装记录。GitHub 用户名和仓库名匹配不区分大小写。

升级后执行：

```sh
dm self-update
dm install https://github.com/guangl/dm-database-sqllog2db.git
dm sqllog2db --help
```

旧版 sqllog2db 保留独立命令帮助文本和配置行为，不提供 SDK 插件入口。SDK 同步版本为 0.4.1，插件协议仍为 API 1。

宿主及内置 db/ssh 插件继续提供 Linux x86_64 GNU/musl、Linux ARM64、macOS Apple Silicon/Intel 和 Windows x86_64 归档及 SHA-256 校验文件。

发布流程同时包含 UTF-8 元数据读取修复和既有标签重试支持。
